# X (Twitter) Captions Playbook — Chibi Anime Loops

Captions engineered for the 20 Seedance 2.0 loops in `seedance_x_viral_loops.md`.

## Caption Rules for X

1. **Max 1–2 lines.** X truncates the rest. The hook must live on line 1.
2. **Max 2 hashtags.** More than 2 = algorithm penalty on X.
3. **No outbound links** in the main tweet (kills reach by 40–60% on X). Put links in a reply thread.
4. **Native video upload only.** Never link to YouTube inside the tweet.
5. **Zero emojis in the hook** — they compete with your thumbnail. One emoji at the end max.
6. **Hook patterns that work on X in 2026:**
   - **POV:** "POV:" sets the frame instantly
   - **Stat:** small numbers ("3 petals. 3 slashes.")
   - **Question:** one-word question that demands the video to answer
   - **Character line:** mascot "speaks" in quotation marks (personifies the brand)
   - **No-context drop:** just a mood phrase. Video does the work.
7. **First tweet = clip only.** Reply to yourself with context, credits (invideo + Seedance 2.0), and prompt snippet — drives bookmark & reply engagement.

---

## The Three-Caption System (write all three per post)

For every clip, write:
- **A = Safe caption** (mood/aesthetic — lowest-risk, good baseline)
- **B = Curiosity caption** (question or cliffhanger — best for new followers)
- **C = Character caption** (mascot voice — builds brand, best for returning followers)

A/B/C test over 3 weeks to see which pattern your audience prefers. Lock in the winner.

## Reply-to-Self Template (post this as reply 30 seconds after the main tweet)

```
Made with invideo.io + Seedance 2.0.
10s loop, 720p vertical, ~200 credits (~$2).
Prompt snippet & mascot lore in 🧵 below if you want to try it yourself.
```

Then drop a mini thread (3–4 tweets) with:
1. The exact prompt (truncated to 280 chars)
2. Why the loop works (one-sentence technical note: "first frame = last frame")
3. The mascot's "origin" (one line — builds lore, makes people follow for the character not the tool)
4. CTA: "Which mascot should I post tomorrow?" + poll (Mochi / Kuma / Nami / Tama)

The poll is huge on X — forces audience to commit and the algorithm rewards poll engagement.
